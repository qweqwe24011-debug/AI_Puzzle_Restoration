# # AI Puzzle Restoration

> Восстановление повреждённых изображений из перемешанных фрагментов с использованием нейросетевой сборки пазла и ансамбля моделей Image Restoration.

## 📌 О проекте

Проект решает задачу восстановления исходного изображения **480×480 px** из **576 перемешанных фрагментов размером 20×20 px**.

Каждый фрагмент независимо повреждён различными типами искажений:

* Gaussian Noise;
* изменение яркости;
* изменение контраста;
* Gaussian Blur;
* JPEG-компрессия.

Поэтому задача состоит не только в правильной сборке пазла, но и в последующей реставрации изображения.

Основная метрика качества — **SSIM (Structural Similarity Index)**.

---

## 🎯 Задача

На вход алгоритм получает:

```text
576 × 20×20×3
```

перемешанных и искажённых RGB-фрагментов.

Необходимо получить:

```text
480×480×3
```

изображение, максимально похожее на исходное.

Главная сложность заключается в том, что соседние фрагменты могут иметь различные уровни шума, яркости, контраста и JPEG-артефактов. Поэтому даже правильно собранный пазл может иметь хорошо заметные швы между фрагментами.

---

# 🧠 Общая архитектура

Решение построено как **двухэтапный pipeline**:

```text
                 INPUT
                   │
                   ▼
       576 corrupted fragments
                   │
                   ▼
              ┌─────────┐
              │ PairCNN │
              └────┬────┘
                   │
          Neighbor prediction
                   │
                   ▼
        Smart Corner Selection
                   │
                   ▼
          Greedy Puzzle Solver
                   │
                   ▼
        480×480 assembled image
          (noise + visible seams)
                   │
                   ▼
        ┌─────────────────────┐
        │  Restoration Ensemble│
        │                     │
        │ UNet + ResNet + Wide│
        │        UNet         │
        └──────────┬──────────┘
                   │
                   ▼
             FINAL IMAGE
```

### Этап 1 — Puzzle Solving

Нейросеть **PairCNN** определяет взаимное расположение двух фрагментов.

После этого используется алгоритм **Smart Greedy Assembly**, который собирает всю сетку.

### Этап 2 — Image Restoration

Собранное изображение передаётся ансамблю из трёх моделей:

* `RestorerUNet`;
* `RestorerResNet`;
* `RestorerWideUNet`.

Ансамбль удаляет шум, JPEG-артефакты и сглаживает границы между фрагментами.

---

# 🧩 Этап 1: PairCNN

## Архитектура

PairCNN получает два фрагмента, объединённых в изображение:

```text
40 × 40 × 3
```

Модель состоит из нескольких сверточных блоков:

```text
Input
  │
  ├── Conv2d
  ├── BatchNorm
  ├── ReLU
  └── MaxPool
       │
       ├── Conv2d
       ├── BatchNorm
       ├── ReLU
       └── MaxPool
            │
            ├── Conv2d
            ├── BatchNorm
            ├── ReLU
            └── MaxPool
                 │
                 ▼
               256
                 │
             Linear
              256→128
                 │
               ReLU
                 │
            Dropout 0.3
                 │
             Linear
              128→3
                 │
                 ▼
              CLASS
```

Модель классифицирует пару по трём классам:

| Класс | Значение                         |
| ----- | -------------------------------- |
| `0`   | фрагменты не являются соседями   |
| `1`   | второй фрагмент находится справа |
| `2`   | второй фрагмент находится снизу  |

---

# 🏋️ Обучение PairCNN

Одной из главных особенностей проекта является обучение на **искусственно повреждённых данных**.

Используется функция `corrupt_fragment`, которая генерирует искажения непосредственно во время обучения.

Это позволяет не создавать один фиксированный повреждённый датасет, а получать новые варианты каждого примера.

## Используемые искажения

### Контраст

```text
uniform(0.70, 1.30)
```

### Яркость

```text
uniform(-30, +30)
```

### Gaussian Blur

```text
radius = 1.0
probability = 95%
```

### JPEG compression

```text
quality = 35–50
probability = 95%
```

### Gaussian Noise

```text
σ = uniform(40.0, 55.0)
```

Таким образом, PairCNN учится определять соседство не по конкретным значениям пикселей, а по более устойчивым визуальным признакам.

---

# 🔲 Smart Corner Selection

Обычная жадная сборка имеет проблему: если неправильно выбрать первый фрагмент, ошибка может распространиться на всю сетку.

Поэтому используется специальная оценка потенциального верхнего левого угла:

```text
corner_score =
    outgoing_score - incoming_score
```

В реализации учитываются максимальные оценки связей справа и снизу, а также обратные оценки.

Идея заключается в том, чтобы найти фрагмент, который:

* хорошо продолжает другие фрагменты;
* при этом сам редко оказывается продолжением другого фрагмента.

---

# 🧱 Greedy Puzzle Assembly

После расчёта `corner_score` выбираются **30 лучших кандидатов** на роль верхнего левого фрагмента.

Для каждого кандидата:

1. запускается сборка;
2. для каждой позиции выбирается наиболее подходящий сосед;
3. рассчитывается внутренняя согласованность полученной сетки;
4. результат сравнивается с другими вариантами.

Финальной становится сборка с максимальным суммарным score.

Таким образом:

```text
576 fragments
      │
      ▼
corner scores
      │
      ▼
Top-30 candidates
      │
      ├── Assembly #1
      ├── Assembly #2
      ├── ...
      └── Assembly #30
              │
              ▼
      Best consistency score
              │
              ▼
        Final puzzle
```

# 🎨 Этап 2: Image Restoration

Даже если все фрагменты расположены правильно, итоговое изображение может выглядеть следующим образом:

```text
┌────┬────┬────┐
│    │    │    │
├────┼────┼────┤
│    │    │    │
├────┼────┼────┤
│    │    │    │
└────┴────┴────┘
```

На границах фрагментов возникают различия:

* яркости;
* контраста;
* уровня шума;
* JPEG-артефактов.

Для устранения этих проблем используется ансамбль реставрационных моделей.

---

# 🧠 Restoration Ensemble

## 1. RestorerUNet

U-Net архитектура со `skip-connections`.

Используется для сохранения:

* глобальной структуры;
* локальных деталей;
* контуров;
* пространственного контекста.

---

## 2. RestorerResNet

Residual-сеть с **8 блоками**.

Основная задача:

* подавление высокочастотного шума;
* восстановление локальной структуры;
* сохранение основных контуров.

---

## 3. RestorerWideUNet

Более широкая версия U-Net.

Она позволяет модели лучше захватывать пространственный и цветовой контекст изображения.

---

# 🔄 Residual Learning

Реставрационные модели не пытаются полностью сгенерировать изображение заново.

Вместо этого сеть учится предсказывать **поправку**:

```text
Network(Input) = correction
```

После чего:

```text
Output = Clamp(
    Input + Network(Input),
    0,
    1
)
```

То есть модель должна научиться в основном предсказывать:

```text
noise + seams + artifacts
```

а исходную структуру изображения сохранить через вход.

Это делает задачу восстановления проще для сети.

---

# 📉 Loss Function

Для обучения реставратора используется:

```text
L1 Loss / MAE
```

L1 Loss сравнивает абсолютные различия между предсказанным и целевым изображением.

В проекте он выбран вместо MSE/L2, поскольку меньше чувствителен к отдельным сильным выбросам и позволяет получать более чёткое восстановление.

---

# 🤝 Ensemble Averaging

После обучения трёх моделей их предсказания объединяются:

```text
             Input
               │
       ┌───────┼───────┐
       ▼       ▼       ▼
     UNet    ResNet  WideUNet
       │       │       │
       ▼       ▼       ▼
      P1      P2      P3
       └───────┼───────┘
               │
             MEAN
               │
               ▼
          Final Image
```

Усреднение позволяет уменьшить влияние индивидуальных ошибок каждой модели.

# 📈 Почему pipeline работает

Основная идея проекта — разделить две разные задачи:

```text
       STRUCTURE
           │
           ▼
     Puzzle Solver
           │
           ▼
      Correct layout
           │
           ▼
        QUALITY
           │
           ▼
   Image Restoration
           │
           ▼
      Clean image
```

Если пытаться решить обе задачи одновременно, модель должна одновременно понять:

* где находится каждый фрагмент;
* какие фрагменты являются соседями;
* как восстановить повреждённые пиксели;
* как исправить границы.

Разделение на два этапа позволяет каждой части pipeline специализироваться на своей задаче.

# 🔬 Возможные улучшения

## Feature Matching

PairCNN можно заменить или дополнить извлечением признаков из предобученных моделей:

* ResNet18;
* VGG16.

Это потенциально позволит сделать сопоставление более устойчивым к экстремальным искажениям.

## Более мощные Restorer-модели

В качестве дальнейшего развития можно использовать современные архитектуры:

* SwinIR;
* Restormer.

Они используют механизмы attention и могут лучше восстанавливать сложные текстуры.

## Улучшение Puzzle Solver

Вместо чисто жадной сборки можно исследовать:

* глобальную оптимизацию;
* beam search;
* графовые методы;
* feature matching;
* joint optimization.
